# Puspa's website

This is a complete portable copy of Puspa Shukla's website, including the corrected U-GO captions and résumé. The site uses plain HTML, JavaScript and local assets. No build or account credentials are required.

## Preview

Extract the ZIP and open a terminal in this folder. Run `python3 -m http.server 8000`, then open http://localhost:8000. Keep the `assets` folder beside `index.html`.

## Make it your own

Edit `index.html` to change text, links or styles. Replace images, the video or the résumé in `assets` while keeping their names, or update the matching paths in the HTML. The fonts and U-GO graphics included here are the assets used by the original website; confirm permission before reusing branding for a different purpose.

## Publish

Upload this folder to a static website host, such as Netlify. Select this folder as the publish directory; no build command is needed. Use your own account and project when creating a separate website. The original published version is https://puspa-shukla.netlify.app.

This copy includes the website's public content and contact links. It excludes account credentials, private project state and class source materials.
